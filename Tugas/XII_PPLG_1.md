Apa yang dimaksud dengan GitHub?
GitHub adalah tempat penyimpanan online berbasis cloud buat ngatur versi kode dan kerja bareng tim pakai sistem Git. Jadi, para developer bisa nyimpen, ngatur, ngelacak perubahan, sampai kolaborasi bikin program bareng-bareng di satu tempat (repository).

Apa Fitur dan Komponen Utama GitHub?
Repository (Repo): Folder atau tempat buat nyimpen semua file proyek, mulai dari kode, dokumentasi, sampai riwayat perubahannya.
Commit: Catatan riwayat atau status saat kita nyimpen perubahan kode.
Branch (Cabang): Cabang terpisah buat ngerjain fitur baru atau perbaikan tanpa ngotak-ngotik kode utama (main).
Pull Request (PR): Fitur buat ngajuin penggabungan kode dari branch kita ke branch utama, sekaligus tempat buat diskusi dan ngecek kodenya bareng-bareng.
Issues: Fitur buat nyatet tugas, ngelaporin error (bug), atau ngobrolin ide baru.
Actions: Fitur buat otomatisasi tugas, kayak ngetes program otomatis atau nge-deploy aplikasi.

Sebutkan Alur Utama (GitHub Workflow)?
Secara umum, langkah-langkahnya begini:
Fork/Clone: Nyalin repository utama ke akun sendiri atau download ke komputer lokal.
Create Branch: Bikin branch baru khusus buat ngerjain tugas tertentu supaya aman.
Make Changes & Commit: Nulis atau ngerubah kode di komputer, terus simpan perubahannya pakai commit.
Push: Ngirim branch beserta kodenya dari komputer lokal ke GitHub.
Pull Request: Ngajuin permintaan supaya kode kita bisa digabung ke branch utama (main).

Apa keuntungan utama dari pembatasan branch main?
Keamanan Kode: Mencegah perubahan langsung yang sembarangan ke kode utama, jadi program yang lagi jalan nggak gampang error.
Kontrol Kualitas: Memastikan semua kode baru wajib dicek dulu lewat Pull Request sebelum resmi digabung.
Kolaborasi Rapi: Bikin kerja tim lebih terstruktur karena kelihatan siapa yang ngerubah kode apa dan tujuannya jelas.
